# ผลทดสอบทางเทคนิค ReBuild สำหรับใช้ประกอบรายงาน

วันที่ 3 ตุลาคม 2569 เวอร์ชันซอฟต์แวร์ 5125774

- ทดสอบฟังก์ชัน กฎข้อมูล API และ SQL ด้วย Vitest: ผ่าน 99 จาก 99 กรณี ไม่ผ่าน 0 ข้าม 0
- ทดสอบการใช้งานอัตโนมัติด้วย Chromium ผ่าน Playwright: ผ่าน 51 จาก 51 กรณี ไม่ผ่าน 0 ข้าม 0 ที่ความกว้าง 1440, 768 และ 360 พิกเซล
- ตรวจการเข้าถึงด้วย axe ในหน้าที่กำหนด 75 ครั้ง ไม่พบข้อผิดพลาดตามกฎที่ตรวจ ไม่ใช่การรับรอง WCAG ครบทุกประเด็น
- ตรวจ TypeScript การสร้าง production และ lint ผ่านสำหรับโค้ดรุ่นนี้ มีคำเตือนขนาดไฟล์ JavaScript ที่ไม่ทำให้ build ล้มเหลว
- ตัวนับการโพสต์ทดสอบการปิดและเปิดฐานข้อมูลในเครื่องใหม่แล้วยังคงค่า ตรวจสิทธิ์ผู้ใช้ทั่วไปและกรณีฐานข้อมูลไม่พร้อม ไม่อ้างว่าได้ทดสอบรีสตาร์ต Render จริงแล้ว

99 และ 51 เป็นจำนวนกรณีทดสอบซอฟต์แวร์ ไม่ใช่จำนวนผู้เข้าร่วมวิจัย ตัวทดสอบใช้ข้อมูลสังเคราะห์และจำลองบัญชีในส่วนที่เกี่ยวข้อง ไม่ใช่คำตอบจากคนจริง

ผู้ใช้รายงานว่า Google และอีเมลเข้าสู่ระบบได้ อนุมัติและลบความคิดเห็นได้ และส่งภาพการรัน SQL สำเร็จ เป็นหลักฐานเฉพาะการลองเหล่านั้น ผู้ช่วยยังตรวจเว็บที่ deploy ใหม่โดยตรงไม่ได้เพราะ proxy ของสภาพแวดล้อมปฏิเสธการเชื่อมต่อ จึงไม่สรุปว่า deployment ล่าสุดผ่านการทดสอบครบ

ข้อความที่นำไปใส่บทที่ 4 ได้: “ผู้พัฒนาได้ตรวจสอบซอฟต์แวร์รุ่น 5125774 ด้วยกรณีทดสอบฟังก์ชัน/API/SQL จำนวน 99 กรณี และกรณีทดสอบผ่านเบราว์เซอร์อัตโนมัติจำนวน 51 กรณี ผลผ่านทุกกรณีที่ดำเนินการ ขอบเขตนี้ไม่ครอบคลุมการทดลองใช้กับผู้เข้าร่วม การเรียนรู้ หรือผลการสร้างชิ้นงานจริง ซึ่งจะรายงานแยกภายหลังการเก็บข้อมูล”
