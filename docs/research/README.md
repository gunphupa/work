# เอกสารสนับสนุนโครงงาน ReBuild

เอกสารนี้เป็นโครงร่างทั่วไป ยังไม่ได้ปรับให้ตรงโรงเรียน เพราะยังไม่ได้รับไฟล์ `แบบฟอร์มโครงงานวิทยาศาสตร์ 5 บท เตรียมวิศว.pdf` และ `การนำเสนอวิจัย 5 บท.pdf` ไม่ใช้ตัวเลขตัวอย่างของโรงเรียนเป็นผลจริง

## ขอบเขตและวัตถุประสงค์

พัฒนาเว็บภาษาไทยสำหรับรวบรวมสิ่งของ ตรวจความพร้อมของโปรเจกต์ Arduino จากข้อกำหนดที่มีแหล่งอ้างอิง และบันทึกกระบวนการสร้าง เป้าหมายด้านซอฟต์แวร์คือรักษาความไม่แน่นอน ไม่แนะนำว่าพร้อมเมื่อยังขาดของ/สเปก และเก็บข้อมูลต่อเนื่องระหว่างคลังกับโต๊ะทำงาน

ไม่รวมวงจรไฟบ้าน แบตเตอรี่ชำรุด สารอันตราย โครงสร้างรับน้ำหนักคน และการพิสูจน์การลดขยะจริงในระยะนี้

## คำถามวิจัยและสมมติฐานที่เสนอ

- ระบบจัดสถานะความพร้อมได้ตรงกับเกณฑ์ที่ผู้ตรวจอิสระกำหนดหรือไม่? สมมติฐานที่เสนอ: ชุดทดสอบครอบคลุมขอบเขตที่ระบุผ่านทั้งหมด โดยต้องรายงานข้อผิดพลาดทุกกรณี
- เมื่อใช้ชุดสิ่งของและงานเดียวกัน ผู้ใช้จัดทำแผนที่ใช้งานได้เร็วขึ้นเมื่อใช้ ReBuild หรือไม่? นี่เป็นสมมติฐาน ยังไม่มีผลสนับสนุน
- AI ระบุชนิดวัตถุและสเปกสำคัญจากภาพได้ถูกต้องเพียงใด? ยังไม่มีข้อมูลจริงเพราะบริการ AI ยังไม่เชื่อมต่อ

## นิยามเชิงปฏิบัติการ

- “พร้อมทำ”: ข้อกำหนดจำเป็นทุกข้อ รวมเครื่องมือ ปริมาณ และสเปกสำคัญ ผ่านการยืนยันและจัดสรรชิ้นส่วนโดยไม่ซ้ำในงานเดียว
- “แผนที่ใช้งานได้”: ผู้ประเมินตรวจว่ามีเป้าหมาย รายการของครบ จุดที่ไม่แน่ใจ แหล่งคู่มือ และขั้นตอนทดสอบที่สอดคล้องกัน
- “การยืนยัน”: ผู้ใช้ตรวจและบันทึกชนิด/ปริมาณ/สเปก ไม่เท่ากับการทดสอบความปลอดภัยทางกายภาพ
- “ตรวจจากเอกสาร”: อ่านแหล่งอ้างอิงและตรวจความสอดคล้อง ไม่ใช่ประกอบสำเร็จ
- “การเรียนรู้” และ “การใช้วัสดุซ้ำจริง”: ต้องมีแบบวัดก่อน–หลังหรือหลักฐานชิ้นงานจริงตามลำดับ ห้ามสรุปจากจำนวนคลิก

## เค้าโครง 5 บท

1. บทนำ: ปัญหา เป้าหมาย ขอบเขต และนิยาม — ร่างได้จากเอกสารนี้; ข้อมูลทีม/อาจารย์ยังรอ
2. เอกสารที่เกี่ยวข้อง: Arduino, structured validation, inventory matching, privacy — ใช้ทะเบียนแหล่งอ้างอิงที่ตรวจจริง
3. วิธีดำเนินงาน: สถาปัตยกรรม แผนทดสอบทางเทคนิค และวิธีศึกษาผู้ใช้ที่เสนอ — มีร่าง; แผนผู้ใช้ต้องตกลงกับอาจารย์
4. ผล: รายงานเฉพาะผลซอฟต์แวร์ใน `../TEST_REPORT.md`; ผลคน ภาพ AI และชิ้นงานจริงยังไม่มี ห้ามเติมข้อมูลสมมติ
5. อภิปราย/สรุป: อธิบายข้อจำกัดจากผลที่มีจริง; ข้อสรุปเรื่องเพิ่มการเรียนรู้/ลดขยะยังรอหลักฐาน

ไม่สร้างสถิติ p-value จำนวนผู้เข้าร่วม ความคิดเห็น หรือกราฟผลลัพธ์ที่ไม่ได้วัด
