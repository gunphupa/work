# เอกสารสนับสนุนโครงงาน ReBuild

แผนเก็บข้อมูลฉบับปัจจุบัน: [STUDY_KIT_TH.md](STUDY_KIT_TH.md) — เน้นงานในบ้าน การอ่านคู่มือเมื่อวัสดุไม่ครบ การวางแผน และการบันทึกงาน มีทางเลือกเปรียบเทียบกับคู่มือข้อความ

ผลซอฟต์แวร์จริง: [TEST_REPORT.md](../TEST_REPORT.md) และผลจากตัวรันใน `../evidence` แยกผลอัตโนมัติออกจากข้อมูลผู้เข้าร่วม ระบบมี 37 โครงงานและ 94 ประเภทวัสดุ รวม Arduino แต่ไม่ได้จำกัดเฉพาะ Arduino

แบบฟอร์มโรงเรียน DOCX ที่ผู้ใช้อัปโหลดถูกใช้จัดร่างรายงาน 5 บทก่อนหน้านี้ ชุดนี้เตรียมวิธีเก็บข้อมูลต่อจากร่าง ไม่อ้างว่าอาจารย์อนุมัติแล้ว

## ไฟล์และขอบเขต

- `STUDY_KIT_TH.md`: คำชี้แจง ภารกิจ เกณฑ์ แบบสอบถาม วิธีสรุป และทางเลือกเปรียบเทียบ
- `USABILITY_TH.md`: ชี้ไปยังแผนปัจจุบัน
- `TEST_PLAN.md`: แผนเทคนิค การรู้จำภาพ และชิ้นงานจริงส่วนขยาย; งาน AI/กายภาพยังไม่ได้ทำ
- `EVIDENCE_REGISTER.md`: แยกสิ่งที่วัดจริง สิ่งที่ผู้ใช้รายงาน และสิ่งที่ยังรอ
- `TECHNICAL_REPORT_2026_10_02.md`: บันทึกทางเทคนิคเดิม เก็บไว้เป็นประวัติ; ใช้ TEST_REPORT.md สำหรับผลล่าสุด

ไม่ใส่จำนวนผู้เข้าร่วม คะแนน แบบสอบถาม p-value หรือข้อสรุปการเรียนรู้/ลดขยะที่ยังไม่ได้เก็บจริง เก็บคำตอบรายบุคคลนอก GitHub; อัปโหลดเฉพาะแบบฟอร์มว่าง วิธีวิจัย และผลรวมที่ไม่ระบุตัวตน

ดาวน์โหลดแบบฟอร์มว่างจาก [templates](templates/): เอกสาร Word/PDF แผนทดลอง, Excel บันทึกผล และคู่มือข้อความสำหรับเปรียบเทียบ สูตร Excel ตรวจด้วยข้อมูลจำลองในไฟล์ชั่วคราวแล้ว แต่ไฟล์ที่แจกไม่มีข้อมูลจำลองดังกล่าว
