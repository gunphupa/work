## สถานะการค้นและการอ่านเอกสาร — สำคัญ
รายการ 8 เรื่องเป็นบทความที่มี DOI ซึ่งรวบรวมจากความรู้ที่มี ไม่ใช่รายการที่ตรวจฉบับเต็มผ่านฐานข้อมูลได้แล้วในครั้งนี้
การเปิด Crossref ถูก proxy ปฏิเสธด้วย 403 จึงยังตรวจทะเบียน บทคัดย่อ และฉบับเต็มออนไลน์เพิ่มเติมไม่ได้ ทุกเรื่องมีสถานะรอตรวจต้นฉบับ ไม่เติมขนาดตัวอย่าง สถิตินัยสำคัญ หรือผลเชิงตัวเลขจากการคาดเดา
ไม่มี PDF บทความฉบับเต็มในชุด ZIP นี้ ลิงก์ DOI อาจพาไปสำนักพิมพ์ที่ต้องใช้สิทธิ์ห้องสมุด; ให้ค้นฉบับเผยแพร่โดยผู้แต่งหรือคลังมหาวิทยาลัยอย่างถูกต้องได้
ชุดนี้ยังไม่ใช่รายงานพร้อมส่งโดยไม่มีการตรวจเพิ่ม โดยเฉพาะบทที่ 2 การอภิปรายอิงงานอื่น และข้อมูลจริงที่ยังเว้นไว้
ได้บันทึกโดเมนฐานข้อมูลที่ต้องใช้ไว้ในร่างการตั้งค่าสภาพแวดล้อมแล้ว หากต้องการให้ตรวจออนไลน์ต่อ ให้เปิด Environment settings และอนุญาตการเข้าถึงโดเมนเหล่านั้นก่อน (เช่น api.crossref.org, doi.org และโดเมนสำนักพิมพ์) การบันทึกร่างอย่างเดียวไม่ยืนยันว่าเครือข่ายอนุญาตแล้ว

## เลือกเอกสารให้ตรงโจทย์
- R1–R2: การวิจัยเชิงออกแบบและการพัฒนาต้นแบบ — ใช้บทที่ 1–3 และอธิบายวิธีรายงานหลักฐาน
- R3: บริบทเศรษฐกิจหมุนเวียน/การใช้ทรัพยากร — ใช้กำหนดขอบเขต ห้ามแทนผลวัดขยะ
- R4–R5: การเรียนรู้ผ่านโครงงาน และภาพกับคำอธิบาย — ใช้เป็นเหตุผลออกแบบ ห้ามแทนผลการเรียนรู้ของ ReBuild
- R6: SUS — สำหรับศึกษาเครื่องมือรอบต่อไป คะแนนดาวปัจจุบันไม่ใช่ SUS
- R7: การวิเคราะห์ข้อความ — ศึกษาวิธีลงรหัสอย่างเป็นระบบ ไม่อ้างว่าได้ทำครบแล้ว
- R8: TAM — เอกสารเสริม ใช้เมื่อจะวัดการยอมรับจริง ไม่จำเป็นต้องใส่ทุกกรอบในงานเดียว

## วิธีตรวจบทความก่อนนำไปเขียน
1. เปิด DOI แล้วตรวจชื่อเรื่อง ผู้แต่ง ปี วารสาร เล่ม ฉบับ และหน้า
2. อ่านบทคัดย่อเพื่อคัดว่าตรงคำถามวิจัยจริงหรือไม่ จากนั้นอ่านวิธีวิจัย ผล และข้อจำกัดของฉบับเต็ม
3. บันทึกว่างานศึกษากับใคร วัดอะไร ใช้เครื่องมือใด และข้อสรุปมีขอบเขตแค่ไหน โดยไม่ใส่ข้อมูลหากไม่พบ
4. จดเลขหน้าหรือหัวข้อที่รองรับข้อความที่ต้องการอ้างในชีตงานวิจัย
5. เขียนสรุปด้วยภาษาตนเอง แล้วระบุว่า ReBuild นำส่วนใดมาใช้และต่างจากบริบทเดิมอย่างไร
6. ลบหรือแก้ข้อความในร่างที่ไม่สอดคล้องกับสิ่งที่อ่านจริง เติมงานใกล้เคียงช่วง พ.ศ. 2564–2569 และงานไทยหากอาจารย์กำหนด

## ใช้กับ Canva
ดาวน์โหลด PPTX → เปิด Canva → อัปโหลด/นำเข้าไฟล์ → เปิดสไลด์เสริม → คัดลอกหน้าที่ต้องการไปงานหลัก
- สไลด์ 1–2: ใช้อธิบายกรอบงานวิจัยและวิธีดำเนินการ
- สไลด์ 3–4: ใช้ในบทที่ 2 แทนการเรียกเว็บไซต์ตัวอย่างว่าเป็นงานวิจัย
- สไลด์ 5: กรอบแนวคิด แก้ข้อความและรูปทรงได้ใน PowerPoint; ตรวจการนำเข้า Canva อีกครั้ง
- สไลด์ 6: เชื่อมวัตถุประสงค์ เครื่องมือ และหลักฐาน
- สไลด์ 7–8: เอกสารอ้างอิง; เลือกเฉพาะงานที่อ่านและใช้จริง
อย่าลบวัตถุประสงค์ วิธีเก็บข้อมูล ผล ข้อจำกัด หรือที่มา เพื่อให้เหลือแต่ภาพตกแต่ง ภาพควรช่วยอธิบายเนื้อหา ไม่แทนหลักฐาน
