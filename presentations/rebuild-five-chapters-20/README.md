## ลำดับ

## แก้ไขใน Canva

ดาวน์โหลด PPTX แล้วอัปโหลดผ่านหน้าแรก Canva → นำเข้าไฟล์ / Import file จากนั้นตรวจให้ครบ 20 หน้า เทียบรูปแบบกับ PDF โดยเฉพาะฟอนต์ไทย ตาราง และกราฟหน้า 14 หากฟอนต์ถูกแทนใช้ Noto Sans Thai สำหรับภาษาไทยและ Noto Sans สำหรับอังกฤษ

ข้อความ รูปร่าง ตาราง และกราฟใน PPTX แก้ไขได้ ภาพหน้าจอเป็นภาพ การนำเข้า Canva อาจเปลี่ยนรูปแบบและการแก้ไขบางองค์ประกอบ โน้ตผู้พูดมีใน PPTX และไฟล์ข้อความแยก เผื่อ Canva ไม่นำเข้าโน้ต

เป็นชุดไฟล์สำหรับนำเข้า Canva ไม่ได้แก้ไขงานในบัญชี Canva โดยตรง

## ข้อมูล

ใส่ชื่อผู้จัดทำ เลขที่ 4 และ 5 ชั้น ม.5/5 ครูที่ปรึกษา ช่วงพัฒนา วิธีคัดเลือกกลุ่มเพื่อน และช่วงทดลองตามที่ผู้ใช้ยืนยันแล้ว คงผลทดสอบและคะแนนจากหลักฐานเดิม ไม่เพิ่มผลภารกิจหรือผู้ทดลองที่ไม่มีบันทึก
