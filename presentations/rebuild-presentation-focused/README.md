# ReBuild — Presentation-focused edition

ปรับเพื่อการพูดนำเสนอ: **19 หน้าหลัก + 7 หน้าสำรอง** โทนเขียวมินิมอล

- เน้นสาธิตการใช้จริงของต้นแบบ วิธีประเมิน ผล และอภิปราย
- แนวคิดและงานวิจัยที่เกี่ยวข้องอยู่หน้าหลักเดียว; บรรณานุกรมเต็มอยู่ท้ายชุด
- มีภาพหน้าจอสาธิต กราฟคะแนนที่แก้ไขได้ และโน้ตผู้พูดทุกหน้า
- กรอบซ้อมประมาณ 15 นาที ไม่รวมถามตอบ (ยังไม่ได้รับเวลานำเสนอที่ยืนยัน)
