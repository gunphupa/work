## นำเข้า Canva

1. ดาวน์โหลดไฟล์ `.pptx` จาก GitHub (หากเปิดหน้าไฟล์ ให้กด Download raw)
2. เปิดหน้าแรก Canva แล้วเลือกอัปโหลด/นำเข้าไฟล์ หรือวางไฟล์ลงในหน้า Canva
3. เปิดงานที่นำเข้าและแก้ข้อความ ตาราง สี และรูปทรงได้ ภาพหน้าจอยังคงเป็นรูปภาพ
4. เติมชื่อผู้จัดทำ อาจารย์ โรงเรียน และปีการศึกษาบนปก แล้วตรวจตำแหน่งข้อความหลังนำเข้า

ไฟล์ PDF ใช้เทียบหน้าตาต้นฉบับ ฟอนต์หลัก Noto Sans / Noto Sans Thai
ยังไม่ได้สร้างหรือแก้ดีไซน์ในบัญชี Canva โดยตรง

## ขอบเขตหลักฐาน

- 21 รีวิวที่เผยแพร่ (19 รีวิวเว็บไซต์ / 2 รีวิวโครงงาน) ณ 3 ต.ค. 2569 เวลา 23:04 น. ประเทศไทย
- เฉลี่ยคะแนนรายการ 3.90/5, sample SD 0.77 ไม่ใช่คะแนนแบบสอบถามมาตรฐาน
- ผู้จัดทำรายงานว่ามีผู้ทดลอง 20 คน ข้อมูลสาธารณะไม่ยืนยันจำนวนคนไม่ซ้ำ
- ที่มาของข้อความและข้อจำกัดการใช้รีวิวระบุไว้ในสไลด์ ไม่อ้างเป็นความคิดเห็นอิสระทั้งหมด
- ซอฟต์แวร์รุ่น 5125774: unit/API/SQL ผ่าน 99 กรณี และ Chromium browser ผ่าน 51 กรณี
- หลักฐานการทดสอบอยู่ใน `docs/evidence` บนสาขา main; ไม่ใช่การทดสอบคน ชิ้นงานจริง หรือผลการเรียนรู้
